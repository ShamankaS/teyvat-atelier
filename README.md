# Teyvat Atelier

Локальный сайт по **Genshin Impact**: загружаете JSON аккаунта, выбираете персонажа и видите, насколько текущий билд отстаёт от гайда в процентах — оружие, сеты, капы статов, таланты — и что менять в первую очередь.

Данные не уходят на сервер: JSON остаётся в браузере (`localStorage`).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:43147](http://localhost:43147). По умолчанию загружается экспорт аккаунта (`public/my-account.json`). Кнопка «Учебное демо» включает маленький искусственный JSON.

Сборка: `npm run build` и `npm start`.

## Формат JSON

Сейчас поддерживается **GOOD v2 и v3** — экспорт [Irminsul](https://github.com/jnrsmcu/Irminsul) и [Genshin Optimizer](https://frzyc.github.io/genshin-optimizer/). Нужны массивы:

- `characters` — `key`, `level`, `constellation`, `ascension`, `talent: { auto, skill, burst }`
- `weapons` — `key`, `level`, `ascension`, `refinement`, `location` (ключ персонажа или пустая строка)
- `artifacts` — `setKey`, `slotKey`, `level`, `rarity`, `mainStatKey`, `location`, `substats`

Свой формат можно будет добавить адаптером, когда пришлёте схему. Пример лежит в `public/sample-account.json`.

## Как считаются проценты

Таблицы в `src/data/guides.ts` — типичный **team DPS** относительно BiS R1 в указанной пачке (не соло-урон). Источники: KQM, TCL и популярные кальки сообщества; цифры округлены.

Предложение «+10 п.п.» — разница табличных процентов (или оценка за кап/основной стат), а не симулятор ротации.

Используются боевые стаки, если сет это подразумевает: Охотник Сумеречного двора +36% крит. шанса, Обсидиановый кодекс +40%.
